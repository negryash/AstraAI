# 🪐 Астра — Telegram бот с ИИ

## Установка

1. Установи зависимости:
```bash
pip install -r requirements.txt
```

2. Запусти бота:
```bash
python main.py
```

## Команды

- `/start` — Знакомство
- `/кто я` — Информация о тебе
- `/астра анализ` — Анализ чата
- `/астра о чём` — Резюме последних сообщений

## Как это работает

- Бот запоминает информацию о пользователях
- Хранит историю чата (последние 50 сообщений)
- Анализирует чат через Gemini
- Может поддерживать разговор и шутить

## Важно

- В @BotFather выключи Privacy Mode, чтобы бот видел все сообщения
- Или добавь бота в группу как админа
